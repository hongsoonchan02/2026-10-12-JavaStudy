## 1일차 -Java 기초

# 자바의 특징
  - 이식성이 좋다 (모든 운영체제에서 실행이 가능)
  - 자동 메모리 해제 (가비지 컬렉션) => 필요시엔 직접 호출 (System.gc())
  - 객체 지향 프로그램 : 조립식 ex) 메인보드
  - 풍부한 라이브러리 존재

# 주의점
  - 모든 프로그램은 main()을 필요로 한다.
  - public 클래스명과 파일명이 동일해야 한다. ex) publci class Main -> Main.java
  - 클래스명, 변수명 등에는 가급적 한글을 사용하지 않는다.

# 주석
  - 여러줄 주석 "/ * * /" => ctrl + shift + / 
 	                  해제  => ctrl + shift + \
  - 한줄 주석 // => ctrl + /

# 컴파일과 실행
  - Java는 소스 코드를 컴파일하여 바이트코드로 변환한 후 JVM에서 실행한다.

```text
Java 소스 코드 (A.java)
          |
          | javac (컴파일러)
          ▼
    A.class (바이트코드)
          |
          | java (JVM 실행)
          ▼
      프로그램 실행
```

## 2일차 - 변수

# 변수
  - 한개의 데이터를 저장하는 메모리 공간
  - 모든 프로그래밍 언어는 RAM에 저장

# 변수의 기본형
```text
  1. 정수 타입
      자료형        크기        저장되는 값의 범위
     - byte     1byte (8bit)     -128 ~ 127
     - char     2byte (16bit)    0 ~ 65,535
     - short    2byte (16bit)    -32,768 ~ 32,767
     - int      4byte (32bit)    -2,146,483,648 ~ 2,147,483,647
     - long     8byte (64bit)    -9,223,372,036,854,775,808 ~
                                  9,223,372,036,854,775,807
```

  2. 실수 타입
| 자료형 | 크기 | 저장되는 값의 범위 |
|---|---|---|
|float | 4byte (32bit) | 1.4E-45 ~ 3.4028235E38 |
|double | 8byte (64bit) | 4.9E-324 ~ 1.7976931348623157E308 |

```text
  3. 논리 타입
       자료형        크기        저장되는 값의 범위
    - boolean  1byte (8bit)       true, false
```

# 타입 변환
  1. 자동(묵시적) 타입 변환
    - 작은 크기의 타입이 큰 크기의 타입에 저장될 때 발생한다.
     ```text
       byte(1) < short(2) < int(4) < long(8) < float(4) < double(8)
       // 단 char는 음수가 저장될 수 없어 byte -> char 자동 변환 불가
     ```

  2. 강제(명시적) 타입 변환 (Casting)
    - 큰 타입을 작은 타입으로 쪼개어 저장하는것.
     ```text
       int intValue = 103029770;
       byte byteValue = (byte)intValue;
       // 결과 : 10 (마지막 1byte만 저장)
     ```
